# Generated oracle expectations

This directory is populated by `tools/omml-oracle/Generate-Oracle.ps1`.
Its MathML, LaTeX, and UnicodeMath files describe the behavior of the pinned
Plurimath oracle; they are comparison data, not normative requirements.

The pinned run converts 260 fixtures in all formats and 19 partially. All 279
produce LaTeX, 278 produce MathML, and 261 produce UnicodeMath. The manifest
records the 19 oracle limitations per output; these are implementation findings,
not unsupported-feature decisions for Docxport.Net.
