# Japanese digit list markers

Retained synthetic DOCX sources and visible Microsoft Word PDF captures cover
japaneseDigitalTenThousand across digit transitions at 10, 100 and 1000,
and its last supported value 9999 followed by empty expansions.
Embedded zeros use U+3007. Four sequences are retained.

`word-evidence.json` records source/capture hashes, starts and visible labels.
PDFs are in [the matching truth group](../../../../../truth/pdf-word/regressions/list-markers/JapaneseDigits/).
Tests reconstruct numbering in memory for Markdown, HTML and plain text.
Generic field formatting retains its current decimal fallback.
