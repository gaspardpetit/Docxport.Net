# Chinese and Taiwanese unit counting list markers

Two retained synthetic DOCX sources and visible Word PDF captures cover
chineseCountingThousand and taiwaneseCountingThousand: zero, unit transitions,
internal zero insertion, omission of initial one for 10 through 19, and the
999999 limit followed by empty expansion. Each capture contains 24 labels.
The formats use different zero and ten-thousand characters.

`word-evidence.json` records source/capture hashes, starts and visible labels.
PDFs are in [the matching truth group](../../../../../truth/pdf-word/regressions/list-markers/ChineseUnitCounting/).
Tests recreate numbering for Markdown, HTML and plain text.
Generic field formatting retains its decimal fallback.
