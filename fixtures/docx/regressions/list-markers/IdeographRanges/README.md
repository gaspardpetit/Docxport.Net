# Traditional and zodiac ideograph marker ranges

Retained synthetic DOCX sources and visible Microsoft Word PDF captures cover
ideographTraditional and ideographZodiac from counter 0 through 60.
Word uses ten traditional symbols or twelve zodiac symbols, then decimal text.
The captured zodiac sequence uses U+620D at position 11.

`word-evidence.json` records source/capture hashes and all 122 visible labels.
PDFs are in [the matching truth group](../../../../../truth/pdf-word/regressions/list-markers/IdeographRanges/).
Tests reconstruct numbering in memory for Markdown, HTML and plain text.
Generic field formatting retains its current decimal fallback.
