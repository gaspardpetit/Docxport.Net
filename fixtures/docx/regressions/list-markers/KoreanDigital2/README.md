# Korean digital2 list markers

The retained synthetic DOCX and visible Microsoft Word PDF capture cover
koreanDigital2 digit substitution from zero through its 999999 limit and the
empty expansion at 1000000. Standalone zero uses U+F9B2; zeros embedded in a
positive number use U+96F6. The capture contains 24 labels.

`word-evidence.json` records source/capture hashes, starts and visible labels.
The PDF is in [the matching truth group](../../../../../truth/pdf-word/regressions/list-markers/KoreanDigital2/).
Tests reconstruct numbering in memory for Markdown, HTML and plain text.
Generic field formatting retains its current decimal fallback.
