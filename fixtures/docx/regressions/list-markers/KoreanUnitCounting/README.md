# Korean unit counting list markers

Six retained synthetic DOCX sources and visible Word PDF captures cover
koreanCounting and koreanLegal, including complete native ones/tens forms,
unit transitions, internal zeros, group-specific omission of one, and the
respective 999999 and 9999999 limits. Both formats are checked through the
signed maximum. Negative values are outside this capture set.

`word-evidence.json` records source/capture hashes, starts and visible labels.
PDFs are in [the matching truth group](../../../../../truth/pdf-word/regressions/list-markers/KoreanUnitCounting/).
Tests recreate numbering for Markdown, HTML and plain text.
Generic field formatting retains its decimal fallback.
