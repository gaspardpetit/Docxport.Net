# Explicit numbering-level caps

Six DOCX/Word PDF pairs cover 18 visible labels for direct numbering-level caps
on/off and absent-property controls, in Latin and Greek. Fresh Word PDF captures
on 2026-11-11 confirm uppercase visible markers when enabled and unchanged
body text. Word ListString retains logical lowercase text; visible PDF labels
are the oracle for the presentation assertions. Both are recorded explicitly.
The manifest records source/capture hashes and extracted PDF labels.
Tests verify HTML, Markdown, plain text and unchanged source document, styles
and numbering XML. Style/paragraph-mark inheritance and reference-field logical
labels remain separate work; this change honors only the explicit level property.
