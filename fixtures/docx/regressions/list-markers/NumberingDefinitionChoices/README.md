# Numbering definition compatibility choices

Twenty-one source documents cover supported choices and unsupported-namespace fallbacks at abstract definitions, instances, levels, overrides, start overrides, and replacement levels. Additional controls cover renamed prefixes, multiple required namespaces, first-supported selection, and a nested choice with a local namespace binding. Direct replacement controls preserve existing start precedence. Each document has six numbered paragraphs.

Expected labels were captured from Microsoft Word ListString and independently confirmed in fresh Word PDF exports on 2026-11-11 and 2026-11-12. See `word-evidence.json` for labels, source/PDF hashes, and paired capture paths.

This group covers numbering definitions only. Paragraph/style compatibility, ignorable ProcessContent wrappers, picture bullets, and marker font properties remain separate scopes.
