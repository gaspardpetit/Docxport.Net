# Japanese kana list markers

Retained synthetic DOCX sources and visible Microsoft Word PDF captures cover
Aiueo and Iroha in half-width and full-width forms, from counter 0 through 60.
These include each complete alphabet and the return to its first symbol.
Half-width Iroha retains the full-width archaic kana without half-width forms.

`word-evidence.json` records source/capture hashes and all visible labels.
PDFs are in [the matching truth group](../../../../../truth/pdf-word/regressions/list-markers/Kana/).
Tests reconstruct equivalent numbering in memory for Markdown, HTML and text.
Generic field formatting keeps its current decimal fallback.
