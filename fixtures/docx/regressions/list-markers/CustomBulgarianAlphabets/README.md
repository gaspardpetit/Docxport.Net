# Custom Bulgarian alphabets

Four DOCX/Word PDF pairs cover 288 labels for upper/lower Bulgarian alphabet
extensions and abstract-zero controls. Word repeats each letter and wraps
after 30 repetitions. Negative expansions are empty and zero expands to a space.
The manifest records source/capture hashes, starts, logical Word labels and raw
PDF extraction. Ignoring extraction whitespace makes every PDF label agree.
Tests verify exact Markdown, HTML and plain text labels and unchanged source
numbering XML.
